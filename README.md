## Proyecto destacado

### StudyMatch — Plataforma de match entre estudiantes

Plataforma web para conectar estudiantes según sus necesidades de estudio, desarrollada en equipo de dos personas y desplegada en producción.

- Frontend completo en React, TypeScript y Vite, con detección de match en tiempo real, notificaciones y sistema de badges.
- Backend en Spring Boot con más de 13 endpoints REST: sesiones, postulaciones, valoraciones, reportes, chat y moderación.
- Infraestructura desplegada en AWS mediante Terraform: EC2, IP elástica, Nginx y Docker.
- Testing end-to-end con Playwright bajo metodología BDD.
- Más de 20 funcionalidades y bugs resueltos de punta a punta.

Stack: React · TypeScript · Vite · Spring Boot · PostgreSQL · AWS · Terraform · Docker · Playwright
